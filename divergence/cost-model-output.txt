5. LATENCY AND THROUGHPUT  (planning assumptions — measure these)
------------------------------------------------------------------------------
model                  parallel    serial    saved  rec/hr (8 conc.)
Opus 5                     214s      293s      79s              134
Sonnet 5 (intro)           132s      181s      49s              218
Sonnet 5 (Sep 1)           132s      181s      49s              218
Haiku 4.5                   64s       87s      24s              452

  The three regime resolvers are independent: they read the same
  upstream state and never read each other. Critical path is 5
  model calls deep, not 7 wide.
  Deterministic checks add ~80ms total and are not on the model budget at all.

  >>> CONSEQUENCE FOR THE DEMO. Even parallelised, a record takes
      minutes, not seconds, because ~12,600 output tokens have to
      be generated. This is a batch product, not an interactive
      one. Do NOT plan a live cold run on stage. The interface
      (Step 23) needs staged progress, not a spinner.
