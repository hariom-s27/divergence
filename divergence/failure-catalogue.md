# FAILURE CATALOGUE — pointer, not a duplicate

The pre-registered, numbered failures (F1–F11) this document's name
promises do not live in a separate file. They live directly inside
[`architecture.md`](architecture.md), under each node's own "**What fails
without it**" heading, with predicted occurrence rates written before any
run. `architecture.md`'s own risk-register section
("WHAT THE RISK REGISTER SAYS ABOUT THIS SHAPE") also ranks them by
Severity × Occurrence × Detection (FMEA-style) and names which node catches
each one.

This file exists only so a reader (or `gate0_check.py`) looking for
`failure-catalogue.md` by name finds a real pointer instead of a 404 —
found and added during the pre-submission audit, 21 August 2026, rather
than silently leaving the name unresolved. Go to `architecture.md` for the
actual content.
