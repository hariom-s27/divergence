# divergence/statutes — versioned Income-tax Act records (D78)
Format and rules: ../DECISION-D78.md. Validator: `python -m divergence.statute_validate`.
- One record = one section (or rule / notification / circular) of one Act, one version.
- Metadata in records/<act>/*.json; bodies in text/ (public_verbatim) or _local_text/ (local_only, git-ignored).
- Nothing here is tax advice or an authentic copy of the law. Verify against the Official Gazette.
- Source: Income Tax Department, Government of India (incometaxindia.gov.in), acknowledged per record.
- Public release of verbatim Act text waits for the s.52(1)(q)(ii) check (see D78).
